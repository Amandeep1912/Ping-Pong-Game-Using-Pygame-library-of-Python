## About the Project
This project is a classic **Ping Pong Game**, where the player controls a paddle and tries to bounce the ball past the opponent’s paddle. The game is played against the computer, which controls the other paddle.

## Features
- Two-player mode (Player vs Computer).
- Adjustable paddle and ball speed.
- Simple and intuitive controls.
- Score tracking system.
- Retro-style graphics using Pygame.

## Installation
To play this game on your local machine, follow these steps:

1. Clone this repository:
   ```sh
   git clone https://github.com/Amandeep1912/Ping-Pong-Game-Using-Pygame-library-of-Python.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Ping-Pong-Game-Using-Pygame-library-of-Python
   ```
3. Install dependencies:
   ```sh
   pip install pygame
   ```
4. Run the game:
   ```sh
   python pingpong.py
   ```

## How to Play
- Use **up arrow** and **down arrow** to move the paddle.
- Try to bounce the ball past the opponent’s paddle.
- The game continues until one player reaches the winning score.
- Press **Esc** to quit the game.
